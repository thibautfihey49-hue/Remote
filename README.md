# DroidRemote - Télécommande Universelle Android

Contrôle TV + Tablettes + Téléphones sur le réseau WiFi

## 🚀 Build APK auto sur GitHub
Push sur main > Actions > Artifacts > Télécharge app-debug.apk
Ou Releases > app-debug.apk

## 📱 Installation
- Téléphone contrôleur: installe APK
- Tablettes à contrôler: même APK + Mode Récepteur + Accessibilité ON

## 🎮 Features
- Scan réseau mDNS + ping
- TV: D-PAD, Power, Home, YouTube/Netflix
- Tablette: Miroir, clavier, verrouiller, screenshot, sonner, volume

Build local: ./gradlew assembleDebug
